# 短时寒潮下的室温服务缺口与巡检归因

业务资料均为合成记录。表头字段及跨表引用见 `fixtures/format.json`。

## 数据说明

气候时段 H1 至 H10 为往年样本，A 是本期冷段，B 是随后巡检段，C 是收到核实的时段，先往年后 A/B/C。室温间隔按小时解释，探头离线、房间不住人和空数值各自保留。sensor-selection 的 residence_floor 是可以推广到楼栋的最低独立住用单位数，本地阈值单位为摄氏度。楼栋热源号相同意味着存在共同运行暴露。
walkthrough 为现场查验，不相当于修复；通知上门所占时段可以持续到改约确认。visits 的记录时间可能晚于被查房间的探头移位时间。楼栋报告可只对具代表性事实声称已解决，局部实测保留单元范围。

CSV 使用 UTF-8、逗号分隔，无引号与内嵌换行。未提供的字段是空字符串，作为关系值的 `-` 表示不适用。多值字段用竖线分隔，数值和日期单位见业务约定。

## 资料检查

使用 Node.js 22.23.4，依赖仅为 Node.js 标准库。运行 `npm ci --ignore-scripts --offline` 准备工作区。

运行 `npm run check:materials` 检查合成交接资料的字段与记录引用。运行 `npm test` 检查交接资料的读取和校验。
